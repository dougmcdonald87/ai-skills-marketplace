# Creator outreach — templates

The Agent Register needs supply before it needs demand. These are the templates for
approaching skill creators directly.

## Why direct outreach

There is no marketplace audience to list in yet, so waiting for creators to find us is
waiting for a chicken. The register has to go to the creators. Every template below is
one-to-one, names a specific skill the creator actually published, and asks for one thing.

## Rules for every message

1. **Name a specific skill and say what it does.** If the message would read the same to
   a different creator, do not send it.
2. **Say the register is new.** It has four entries. Pretending otherwise is how you get
   reported as spam, and it wastes a relationship you only get once.
3. **One link, one ask.** The submission form. Not the catalogue, not Twitter, not a
   "would you like to chat".
4. **No money changes hands for the creator.** They set the price and it goes to their own
   PayPal.me. Say so, because most creators assume marketplaces take a cut.
5. **Make "no" cheap.** One line that makes not replying a fine outcome.
6. **Reply-to must be the address on the site.** The site says submissions go to
   `dottyecho1@gmail.com`, so that is the reply-to. Outreach is sent from that same house
   mailbox, so replies land somewhere that is actually read rather than in a black hole.
7. **British English.** Catalogue, licence, organisation, colour, one-off.

## What NOT to do

- **Do not open a GitHub issue on a creator's repo to pitch the marketplace.** It is
  unsolicited promotion in someone else's space, it violates GitHub's community
  guidelines, and it is the single fastest way to get the domain flagged.
- **Do not mass-send one template with a name merge.** Every message must name a real skill.
- **Do not offer money for a listing.** There is no budget, and a paid listing reads as a
  scam and breaks the no-commission claim you are making.
- **Do not claim the register is busy.** It is not. Say it is new.
