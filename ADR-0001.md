# ADR-0001: Static site + PayPal buttons

## Status
Accepted

## Context
Building an AI agent skills marketplace on a 4GB RAM machine. No budget for hosting, no bank account for payment processing, no time for complex architecture.

## Decision
Use a static HTML/JS site hosted on GitHub Pages (free tier) with PayPal.me links for paid skills. No backend, no database, no user accounts.

## Rationale
- Zero monthly cost (GitHub Pages free tier)
- Zero backend maintenance
- PayPal.me links handle payments without a merchant account
- Static files open instantly on 4GB RAM
- No JavaScript framework — vanilla JS only
- Platform-agnostic: skills work with any AI agent, not locked to Cursor or Claude Code

## Consequences
### Positive
- Free to host
- No server to maintain
- Fast page loads on low-RAM machines
- PayPal is the only payment processor (per user constraint)

### Negative
- No user accounts or skill submission processing (manual curation only)
- Manual skill addition via skills.json edits
- No analytics beyond what PayPal provides

## Amendments

### ADR-0002 — Client-side search and filtering (added 2026-10-18)
The original decision listed "no search or filtering" as a static-site limitation. That was wrong: filtering is a
client-side operation over data that is already loaded, so it needs no backend at all. The catalogue now has a
text search and a category filter, both operating over `skills.json` in the browser. Still zero cost, still no
server. The honest version of the constraint is narrower: **there is no server-side search, and no ranking,
personalisation or analytics.**

### ADR-0002 — Editorial register design + UK locale (see ADR-0002.md)
The design direction and the en-GB / GBP locale decision are recorded separately, because they are separable
concerns with different reasons.

## Alternatives considered
- **Full SaaS with database**: Rejected — 4GB RAM can't run a database, no budget for hosting
- **WordPress/CMS**: Rejected — too heavy, requires database and PHP
- **Stripe integration**: Rejected — requires bank account, user said PayPal only
